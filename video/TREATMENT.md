## 1. 故事

- **主体**：Clawd，Claude Code 的橙色像素吉祥物，住在终端里。
- **目标**：它想开工写代码，但它的"电源线"没接上——没有可用的 API 端点。
- **转折**：一条 `npx qiniu-coding-helper`，蓝色的七牛线路接进来，状态表一行行从 `○ 未接入` 翻成 `● 已接入七牛`。
- **呼应**：开场是空终端里闪烁的光标和一句"？"，结尾回到同一个光标，这次Clawd自己敲出了那条命令。

**视觉母题**：橙（Claude Code）× 蓝（七牛 Logo 渐变 `#00D4FF → #004080`）。全片前半是"橙色孤岛"，接入那一刻蓝色线缆通电，两种颜色第一次同框。

### 三个备选结构

1. **问题 → 向导 → 结果**（线性教程）：清楚，但平。
2. **前后对比**：开头展示配好的结果再倒叙：抓人，但教程步骤被打散。
3. **角色线 + 教程线并行**（选用）：Clawd的"接电"小故事做情绪线，向导五步做信息线，两条在第 9 镜的"状态表翻牌"汇合。既有钩子，步骤又是完整顺序，适合做教程。

## 2. 参考（只学语法，不抄内容）

- Apple 发布会的产品 UI 特写：慢推 + 局部放大 + 干净转场 → 学"UI 当主角"的镜头语法。
- 8-bit 游戏过场：像素角色 + 方波音色 → 学角色的"踩拍"动作和芯片音乐结构。
- 不抄：任何官方 Logo 动画、官方宣传片镜头、已有旋律。

## 7. 字幕与标题设计

- 字幕：底部居中，思源黑体 Medium 44 px，白字 + 60% 黑底条，最长一行 22 字。
- 命令、路径、Key 一律用等宽字体，并在画面中用橙色高亮框框出。
- 标题卡：`qiniu-coding-helper`，等宽粗体，标题卡至少停留 4 s。
- 尾卡：`npx qiniu-coding-helper` + `获取 API Key：portal.qiniu.com`。

## 8. 素材与版权

- 终端 UI 文案全部取自本仓库 `src/locales/zh_CN.json` 和 CLI 实际输出。
- Claude Code 界面元素（✻ 标记、欢迎框、输入框）按真实 CLI 重绘，只用于说明"配置后的效果"。
- 像素Clawd是原创的"Claude Code 风格"角色；**公开发布前**请确认是否要换成自有形象，Anthropic 的官方 Clawd 形象和 Logo 不直接使用。
- 七牛 Logo 使用本项目内置的 ASCII 块字 Logo。
- 截屏中的 API Key 一律打码。
